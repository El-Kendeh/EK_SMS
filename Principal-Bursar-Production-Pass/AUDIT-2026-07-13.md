## P0 — Money correctness + access control (confirmed defects, small surgical fixes)

1. **Finance-Team Suspend is a fake-success no-op** — `updateFinanceUser` (financeController.js:796) flips only the display mirror `SchoolAdmin.is_active`, never `User.is_active` (the real login gate). A "suspended" finance user keeps full access. Fix = mirror `updatePrincipalUser` (principalController.js:529-556): transaction, both flags, self-suspend guard.
2. **FLOAT currency everywhere** — `Fee.amount/discount/amount_due/amount_paid`, `Payment.amount`, `Expense.amount` are `DataTypes.FLOAT`. Migrate to `DECIMAL(12,2)` (models + idempotent ALTER migration; prod by hand), round/compare on 2dp.
3. **Receipt numbers not unique** — `RCP-<base36 ms>` (financeController.js:406), no DB constraint; same-ms payments collide platform-wide. Plan 4.2 requires unique numbers. Fix = `RCP-<schoolId>-<ts>-<random>` + UNIQUE index + retry-on-duplicate.
4. **Lost-update race on `fee.amount_paid`** — read-modify-write inside txn without row lock (financeController.js:425-431). Fix = `fee.increment({amount_paid: amount}, {transaction})` + reload for status.
5. **No server-side amount validation** — `recordPayment`/`recordExpense`/`assignFees` accept negative/zero/NaN amounts. Fix = shared positive-decimal guard.
6. **General payments never credit balance** — `getStudentFees` summary sums only `fee.amount_paid`; a `fee_id:null` payment shows in history but leaves balance unchanged (financeController.js:527-533). Fix = credit unlinked payments in the summary line (and statement view).
7. **Finance Team list unfiltered + bursar sees 403 controls** — list returns every SchoolAdmin row (principals + tenant admin appear); page renders Add/Suspend for bursar role which is 403 on write. Fix = filter to finance roles; hide/disable controls per role.
